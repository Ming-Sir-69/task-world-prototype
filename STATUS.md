# Status: paused / unfinished

This repository preserves a few-hours exploratory prototype. It is not a completed product, commercial release, production task manager, or fully tested game. The experiment did not reach the desired interaction quality and development is paused.

The public version uses only invented demonstration content. Existing movement, rendering and interface experiments are retained so others can inspect the approach. No feature roadmap or maintenance commitment is implied.

Selected engine, scene-reachability and mocked integration checks are available. They do not resolve the interaction shortcomings or establish real-browser/mobile acceptance. See [docs/VERIFICATION.md](docs/VERIFICATION.md) for what was and was not checked.
